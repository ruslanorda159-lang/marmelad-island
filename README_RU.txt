МАРМЕЛАДНЫЙ ОСТРОВ — VERSION 3

ИЗМЕНЕНИЯ:
- 15 видов мармелада.
- Своя картинка для каждой мармеладки.
- Своя картинка бомбы.
- 1 экспедиция в день.
- Экспедиция = 5 волн.
- Каждая следующая волна быстрее.
- С каждой волной растёт шанс появления бомб.
- Размер предметов постепенно уменьшается.
- Комбо и множители.
- Монеты.
- Опыт и уровни.
- Магазин постоянных улучшений.
- Сохранение прогресса в браузере.
- Ранний выход с накопленной добычей.
- Финальная награда после 5 волн.

ВАЖНО ПРО «1 РАЗ В ДЕНЬ»:
Эта версия ограничивает запуск одной экспедиции по локальной дате устройства.
Для Telegram Mini App настоящий честный лимит должен проверяться на сервере через Telegram user ID.
Также для настоящего общего рейтинга, защиты от изменения монет и сохранения между устройствами нужен сервер.
