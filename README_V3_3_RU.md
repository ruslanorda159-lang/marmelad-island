# Marmelad Island v3.3 — Gameplay

Эта версия пока **без сервера**. Она предназначена для полной настройки и тестирования самой игры.

## Что изменилось

- Мармеладки и бомбы теперь двигаются по игровому полю по простой физике: скорость, ускорение, отскоки от границ, вращение и срок жизни.
- Размер предметов рассчитывается от реального размера игрового поля.
- Добавлены красивые эффекты попадания и всплывающие очки.
- Комбо увеличивает множитель очков.
- Бомбы сбрасывают комбо.
- Добавлены 4 настоящих активных бустера:
  - 🧲 Магнит — притягивает мармеладки к центру 5 секунд.
  - ⏱️ Время — добавляет время к текущей волне.
  - 💰 x2 монеты — удваивает монеты за мармеладки на 8 секунд.
  - 🛡️ Щит — защищает от следующей бомбы.
- Каждый уровень улучшения даёт соответствующее количество зарядов бустера на каждой волне.
- Все 4 бустера можно нажимать прямо во время игры.
- Игра остаётся адаптивной для Telegram и маленьких экранов.

## Запуск

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Открой адрес Vite в браузере телефона/ПК для тестирования.

## Важно

Сохранение сейчас находится в `localStorage`, потому что сервер мы пока не подключаем. После того как механика и дизайн будут окончательно утверждены, серверную версию можно подключить отдельно, не меняя игровой интерфейс.
